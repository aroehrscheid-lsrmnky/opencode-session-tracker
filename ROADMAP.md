# Roadmap

## Phase 1 – MVP
- Scaffold plugin with manifest
- Bar widget showing session count
- Exporter script for opencode.db → JSON
- Panel with recent sessions list

## Phase 2 – Prompt Library
- Save/load prepared prompts to JSON
- CRUD UI in panel
- Tags, skill association, shortcuts

## Phase 3 – Search & UX
- Full-text search over sessions + library
- Favourites, filters by project/date
- Copy to clipboard / paste into OpenCode

## Phase 4 – Polish
- Theming, keyboard shortcuts
- Settings UI
- GitHub release workflow
