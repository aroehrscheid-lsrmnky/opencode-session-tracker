OpenCode Session Tracker – Omarchy Widget

Goal: A Quickshell/Omarchy bar-widget + panel that gives an overview of OpenCode prompts over time, lets you store prepared prompts, tag them with skills/shortcuts, and keeps your most useful sessions discoverable so you don't lose context.

Project Overview

Omarchy plugins are QML components running inside omarchy-shell. Hot-reload from ~/.config/omarchy/plugins/. This project will be a bar-widget + panel plugin.

  • Bar: session count / last activity pill
  • Panel: Recent sessions, Prompt Library, Search
  • Data source: ~/.local/share/opencode/opencode.db SQLite
  • Bridge: small exporter script → JSON cache for QML

How to create an Omarchy plugin

From the Omarchy cheatsheet:

  1. omarchy plugin clone omarchy.clock --edit
  2. Pick kind → bar-widget entry BarWidget.qml
  3. Write manifest.json with id, name, kinds, entryPoints
  4. Implement BarWidget.qml + Panel.qml, imports QtQuick, Quickshell, qs.Ui
  5. Validate: omarchy plugin validate + qmllint
  6. Install: omarchy plugin add https://github.com/you/repo.git --enable
